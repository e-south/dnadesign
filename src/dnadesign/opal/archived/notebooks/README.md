# Archived OPAL Notebooks

This directory keeps retired OPAL marimo surfaces for reference while the active
notebook path stays focused on current campaign inspection contracts.

`prom60_eda_legacy.py` is the former prom60/LatentDNA atlas-style notebook. It is
not the canonical OPAL campaign-progress surface. Use
`src/dnadesign/opal/notebooks/campaign_progress.py` for the active read-only
campaign progress notebook.
