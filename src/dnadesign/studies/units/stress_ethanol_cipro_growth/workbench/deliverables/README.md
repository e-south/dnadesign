## Stress Study Deliverables

**Owner:** dnadesign-maintainers
**Last verified:** 2026-05-18

These files are LatentDNA-facing study deliverable docs. The deliverable IDs in
workspace config stay stable; this directory only organizes the checked-in prose
by review role.

### Deliverable Lanes

- [Gates](gates/README.md): first-pass acceptance gates that decide whether the
  review path is usable.
- [Primary review](primary/README.md): decision-path deliverables for pre-assay
  interpretation and candidate choice.
- [Native reference](native-reference/README.md): native-reference overlays and
  orientation checks.
- [Appendix](appendix/README.md): supplementary geometry and notebook review
  material.
