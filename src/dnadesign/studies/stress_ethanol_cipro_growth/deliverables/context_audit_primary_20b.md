# Context Audit Primary 20B

This deliverable measures whether the 20B expanded-context lane changes in a
structured way relative to the 60 bp anchor baseline.

The core readouts are self cosine, shift magnitude, and neighborhood
preservation.
Use it to separate a common scaffold shift from promoter-specific
reorganization.
If the expanded-context lane is numerically null, this deliverable should say
so explicitly instead of silently falling back to a weaker interpretation.
