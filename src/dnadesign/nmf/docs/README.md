# NMF Docs

**Owner:** dnadesign-maintainers
**Last verified:** 2026-07-14

Use NMF when motif annotations should be summarized into recurring
co-occurrence programs rather than only scalar diversity metrics.

## Start Here

- [Factorization workflow](factorization-workflow.md): input shape, model
  behavior, rank choice, outputs, and example diagnostics.
- [Billboard docs](../../billboard/docs/README.md): scalar diversity metrics
  that complement NMF program summaries.
- [Repository docs index](../../../../docs/README.md): route into broader
  workflow docs.

The factorization modules are present, but the package does not currently
expose a supported project-script entrypoint. See the workflow's runtime-status
section before attempting an end-to-end run.
