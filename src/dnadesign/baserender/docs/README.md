# BaseRender documentation

BaseRender validates a render job, translates input records, draws declared
sequence or topology facts, and publishes an immutable image bundle. Choose the
route that matches the artifact you have.

## Choose a route

- Start a new job: [technical reference](reference.md).
- Render an artifact from another tool: [integration index](integrations/README.md).
- Run a checked-in example: [workspace demos](demos/workspaces.md).
- Inspect job syntax: [example jobs](examples).

## Boundary

BaseRender owns reusable sequence and declared-topology drawing. An integration
may translate a producer contract into that visual grammar. Calculations,
rankings, statistical diagnostics, and study interpretation remain in the tool
that owns them.

The [repository docs index](../../../../docs/README.md) routes to adjacent
dnadesign tools.
