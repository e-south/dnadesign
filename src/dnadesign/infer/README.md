![Infer sequence inference banner](assets/infer-banner.svg)

Infer runs sequence models to extract likelihoods and numerical features or generate sequences. It accepts local sequence files and SeqLedger datasets, with optional result storage for later analysis.

## Documentation

Start with the [Infer guide](docs/README.md), or [validate your first job](docs/getting-started/cli-quickstart.md) without downloading model weights.

- [Workspaces](workspaces/README.md): keep inputs, configuration and outputs together.
- [Evo2 features](docs/operations/evo2-sequence-features.md): choose sequence context and pooling.
- [Save results in SeqLedger](docs/operations/pressure-test-agnostic-models.md): register output types, run extraction and inspect stored results.
- [Reference](docs/reference/README.md): commands, model settings and feature schemas.

See the [DNADesign documentation](../../../docs/README.md) for other tools and workflows.
