# Assemble shared datasets

Choose what you need to combine, then follow the corresponding procedure. Merging base records does not automatically copy annotations or semantic sequence views.

- [Multi-source assembly](multi-source-shared-dataset.md): combine records and explicitly select annotations to carry.
- [Construct to Infer](construct-infer-shared-dataset-runbook.md): use resolved sequence contexts as model inputs.
- [Permuter to Construct and Infer](permuter-construct-infer-shared-dataset.md): realize contexts for variant records before extracting features.
