## RegulonDB Command Surfaces

Command fragments group read-only checks by owner lane.

- `ops-fill.yaml`: study-level Infer fill planning.
- `usr.yaml`: native dataset validation.
- `construct.yaml`: core60 Construct validation.
- `infer-validation.yaml` and `infer-completion.yaml`: Infer config and
  completion inventory checks.
- `notify.yaml`: Notify event resolution checks.
- `latentdna.yaml`: LatentDNA workspace validation.
