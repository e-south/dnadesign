## RegulonDB Execution Surfaces

These fragments merge into `ops.study.yaml` `parts.execution_surfaces`.

- `workspaces.yaml`: Construct, Infer, and LatentDNA workspace roots.
- `runbooks/`: batch runbook declarations.
- `commands/`: read-only validation, inventory, and fill-plan commands.

This study is record-only for OPS status today. These surfaces support checked-in
route/preflight documentation; they do not imply a registered `ops progress`
provider.
