## Retron Compiler Catalog

Machine-readable registry metadata for study-owned Retron MSD labels and
subcomponents. This is input to the compiler, not generated output.

- `msd_design_registry.yaml`: payload, cap, and construct metadata for
  reference compilation.
- `msd_cap_sources.yaml`: concise `C###` cap source lookup with 5'->3'
  sequences. Do not infer de033 sequence or topology from an id pattern.
