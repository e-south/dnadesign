How a binary target program becomes one MSRB ranking score

Study companion for MSRB v1. It ranks directional binary programs; it does not encode graded, exact, or don’t-care setpoints.

1 · PhenotypeReader produces ordered response and reference-relative signal values.
2 · Target maskThe study labels each measured state intended ON or intended OFF.
3 · MSRBThe objective rewrites desired behavior so every larger value is favorable.
4 · ScoreA soft minimum combines the values into one within-view ranking score.
5 · SelectionA separate selector ranks candidates by decreasing score.

Every symbol names either a measured value, a state group, or one step in the aggregation.

The notation is dense because one equation spans several levels. Keeping those levels separate makes the calculation much easier to read.

ri
Response in state i

Median across design wells of each well’s 4–8-hour mean log2(YFP/CFP); YFP and CFP are expressed from the same plasmid.

bi
Reference-relative signal

Median design-well 4–8-hour log2(YFP/OD600) minus the median pDual-10 value measured in the same state on the same plate.

i, j
State indices

i names one intended-ON state; j names one intended-OFF state in a response comparison.

pi ∈ {0,1}
Binary target for state i

A value of 1 assigns the state to intended ON; 0 assigns it to intended OFF.

O, F
Sets of states

O contains intended-ON states and F intended-OFF states; both must be nonempty. Here F does not mean fluorescence.

dc
One favorable-direction value

One state-level result rewritten so that larger is favorable. Superscripts R, ON, and OFF are family labels, not powers.

f ∈ {R, ON, OFF}
One behavior family

f names response ordering, intended-ON signal, or intended-OFF suppression.

c ∈ Cf
Coordinate inside family f

c indexes one favorable value; Cf is the set of all values in that family.

nf = |Cf|
Number of values in family f

It turns the sum into a family mean, so larger families do not count more merely because they have more comparisons.

τ
Soft-min scale

Controls how readily stronger behavior compensates for weaker behavior. It is not a pass threshold.

Sf
One family score

The soft minimum of every favorable-direction value in family f.

SR
Response-ordering family score

The soft minimum of every intended-ON minus intended-OFF response comparison.

SON
ON-signal family score

The soft minimum of the reference-relative signals in intended-ON states.

SOFF
OFF-suppression family score

The soft minimum of the negated signal values in intended-OFF states.

SMSRB
Final ranking score

The soft minimum of the three family scores. Higher is better only under one fixed mask and τ.

Σ, e, ln
Sum, exponential, natural log

These operations form the soft minimum. The next section explains the role of each one.

The main ontology: measured values r and b → favorable-direction values d → family scores SR, SON, and SOFF → final ranking score SMSRB. The mask pi determines only which states belong to O and F.

MSRB asks three biological questions and writes every answer so that a larger number is favorable.

The sign convention makes each declared preference point upward. Holding the other phenotype values fixed, an intended improvement cannot lower MSRB; one wet-lab change may move several coordinates at once.

1 · Response ordering

Does every intended-ON state have a larger response than every intended-OFF state?

dijR =ri−rj i∈O,j∈F

Read aloud: “Response ordering equals an ON-state response minus an OFF-state response.”

Every ON/OFF pair is included. If either the ON response rises or the OFF response falls, this value improves.

Example: ON response 2.4 minus OFF response 0.9 gives dR = 1.5. At zero the two responses are equal.

2 · Intended-ON signal

Is each intended-ON state bright relative to the reference measured in that same state?

diON =bi i∈O

Read aloud: “ON signal is the design’s reference-relative signal in an intended-ON state.”

No sign change is needed: larger bi already means brighter relative to the reference.

Example: bi = 1 log2 means the design is twice the reference signal in that state. At zero they are equal.

3 · Intended-OFF suppression

Is each intended-OFF state dim relative to the reference measured in that same state?

djOFF =−bj j∈F

Read aloud: “OFF suppression is the negative of the design’s reference-relative signal in an intended-OFF state.”

The minus sign reverses the direction: a lower original OFF signal becomes a larger, more favorable suppression value.

Example: bj = −2 log2 becomes dOFF = 2: the design is fourfold dimmer than the reference. It does not mean absolute non-expression.
Response zero: the particular ON and OFF responses are equal.
ON-signal zero: the intended-ON signal equals the same-state reference.
OFF-suppression zero: the intended-OFF signal equals the same-state reference.

The soft minimum keeps weaker behavior influential without making every stronger value irrelevant.

The same operator is applied twice: first inside each family, then across the three family scores. Algebraically this equals one weighted soft minimum over all state-level values.

Stage 1 · Summarize each family

Sf=−τln ( 1nf ∑c∈Cf e−dc/τ )

f is one family—R, ON, or OFF. Cf is its coordinate set and nf = |Cf| is its number of values. Dividing by nf prevents a family from counting more merely because it contains more comparisons.

Stage 2 · Combine the three family scores

SMSRB=−τln ( e−SR/τ + e−SON/τ + e−SOFF/τ 3 )

The denominator 3 gives the response, ON-signal, and OFF-suppression families equal starting weight. Their realized influence still depends on their values.

What each mathematical operation is doing

−d/τ

Reverses the scale inside the exponential, so smaller or negative behavior values receive more influence.

e−d/τ

Within one averaging stage, a smaller value produces a larger term and therefore greater local influence. Across state-level coordinates, influence also depends on the family’s starting weight.

Σ

Adds the transformed evidence. The index underneath tells you exactly which values are included.

1/nf

Takes a mean inside a family. It solves the unequal-count problem; it is not an uncertainty correction.

ln

Brings the exponential average back onto the original additive scale. It is the natural logarithm because the preceding exponential uses base e.

−τ

Restores the original log2-clearance unit and makes larger final scores favorable.

τ

Sets the compensation distance. Small τ is stricter; large τ is more mean-like. This campaign uses approximately 0.31 log2.

Equal starting weight is not equal final influence. Among the three equally weighted family scores, the lower family score has greater local influence. Positive MSRB is still not a pass criterion.

With the campaign’s τ, moderate behavior in all three families outranks a strong but lopsided profile.

Move the scale to see what τ changes. It changes only the compensation rule—not the phenotype, target mask, or three family definitions.
